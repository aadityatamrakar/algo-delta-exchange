### WP-O: Operator audit log (roadmap 17)
**Files:** new `apps/api/src/audit.ts` (self-contained writer, narrow collection port — the day-guard pattern; collection `desk-audit-log`, append-only, capped read endpoint), audit calls added inside the MUTATING route handlers: `routes/desk.ts` (kill switch set/release, close-all, close-leg, flatten, seed, strategies add/patch/remove, broker cancel — which also gains the principal it never recorded, F-53), `routes/books.ts` (registry create/patch/start/stop/delete, dials), `routes/brokers.ts` (credential edits/tests), `routes/runner.ts` (clear requests); `day-guard.ts` writes its automatic actions with principal `'day-guard'`; new `GET /v1/desk/audit?limit=` (operator) + a compact "Recent operator actions" section on the Status page (`apps/web/src/status.tsx` + api.ts type). Entry shape: `{at, principal, source, action, tag?, mode?, detail (small before/after summary — NEVER credentials/passwords)}`. Fail-soft: an audit write failure logs and never fails the mutation. Tests: writer + 3-4 representative routes + web section render.

### WP-P: Positions-level truth comparison (roadmap 16)
**Files:** new `apps/api/src/positions-compare.ts` + wiring in `main.ts` (localized), new `GET /v1/desk/positions/compare` (operator+machine), Status page gateway card extra or its own row. Compares three sources per contract (live rail only): broker net positions (`desk-broker-snapshot` positions — read the writer for field names; signed netQty), `desk-books` live legs summed per tradingsymbol, runner ledger (`runner:positions` live scopes, lots × lotSize via the master). Runs every `DESK_POSITIONS_COMPARE_MS` (default 300_000, positiveEnvMs) AND once nightly at 16:00 IST with a journalled + notified summary when divergent; endpoint serves the last result + on-demand recompute. Report shape: per symbol `{broker, books, ledger, agree: boolean}` + `unattributable` (broker-only rows — the Python desk's own books legitimately live at the broker too, so a `desk-books` match is EXPECTED to cover them; divergence = books ≠ broker for symbols the books claim, or ledger legs the broker lacks; be honest about what cannot be attributed rather than alarming on the Python desk's normal state). No auto-repair — report only. Tests with fakes.
